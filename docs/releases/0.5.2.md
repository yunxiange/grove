# Grove 0.5.2 · 个人设置整理与阅读偏好返回修复

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.5.2.apk** 安装，版本号 `0.5.2`，内部版本号 `15`。

APK 使用不可调试的 Release 构建，沿用旧版本签名，可直接覆盖升级并保留账号、书签、足迹和偏好。本次发布到 GitHub，尚未上架应用商店。

## 本次更新

- 个人页右上角「更多」整理为「设置」，首页只保留阅读偏好、缓存管理、仓库与账号、关于 Grove 四项。
- 已添加的仓库、仓库授权和退出登录集中在「仓库与账号」；访客仍可管理本机添加的仓库，授权和退出入口仅登录后显示。
- 开发者选项收进「关于 Grove」，保留原有预览诊断功能；缓存管理仍可直接从设置首页打开。
- 修复从个人设置进入阅读偏好后没有返回入口的问题。左上角可返回设置首页，右上角可关闭，修改的字号与纸色会保留。
- 从阅读页直接打开阅读偏好时提供明确的关闭按钮，关闭后回到原文档。

## 验证与边界

164 项 Android 自动化测试、32 项阅读器测试、Release 构建与 Release Lint 通过。已核对 APK 版本、不可调试标志、签名及与旧版的证书兼容性。

首轮全量执行时，3 项后台下载服务停止状态断言未通过；单独运行下载服务测试与再次全量执行均通过，首轮失败未再复现。本次未修改下载服务代码。

原生界面回归覆盖设置分层、登录与访客入口、退出登录、缓存清理、预览诊断，以及阅读偏好返回和设置持久化。界面图使用示例数据在 Compose / Robolectric 下渲染，本次未连接真机。

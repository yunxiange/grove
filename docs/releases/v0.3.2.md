# Grove 0.3.2 · 预发布体验版

首个公开下载版本，目前仅支持 Android 8.0 及以上。此 APK 使用开发签名，尚未完成真机验收。

## 下载安装

下载附件 **Grove-0.3.2-debug.apk**，在 Android 设备上打开安装。包名为 `dev.grove.reader`，版本号 `0.3.2`，内部版本号 `9`。

`Source code` 附件为源码压缩包；手机安装请选择 APK。

## 当前功能

- 纸面风格的项目阅读：Markdown、目录、分支、只读 Issues 与评论。
- 图片、PDF、Excel / CSV 预览；图片长按保存、SVG 预览与源码切换。
- GitHub Star 与文档书签，支持搜索全部 Star；最近访问可排序和移除。
- 分类发现、语言筛选；返回发现页保留滚动位置。
- 收藏和发现支持下拉刷新；分页列表与表格支持滚动续载。
- 底部菜单使用墨色选中背景与加粗文字，增强当前位置辨识度。

## 使用前了解

- 公开仓库可直接阅读；匿名访问受 GitHub API 额度限制。
- GitHub 登录、Star 写入和私有仓库访问依赖 GitHub App 权限及安装授权，远端配置仍待核验，完整登录与私有仓库流程尚未完成真机验收。
- 项目内容和 Issues 为只读；书签与阅读记录保存在本机，暂不跨设备同步。
- 这是开发签名包。后续如果改用正式签名，可能需要卸载此版本后安装；卸载会清除本机阅读数据。

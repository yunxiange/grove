# Grove 0.4.1 · 正式版

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.4.1.apk** 安装，版本号 `0.4.1`，内部版本号 `11`。

这是 GitHub 上的正式发布版本（非预发布），APK 使用不可调试的 Release 构建。为便于已有用户覆盖升级，沿用 0.3.2 / 0.4.0 及本次测试包的开发签名证书，并未切换到应用商店专用证书；账号、本机书签、访问记录和偏好可保留。

## 本次更新

- 底部「仓库」改名为「足迹」，展示访问记录；在足迹内再次点击已选中的底部「足迹」，直接回到首页并保存阅读进度。
- 切换底部导航后恢复各自打开的项目、文档、目录、源码滚动位置与 Issue 详情；PDF 页码与缩放也可恢复。
- 恢复阅读页底部「文件」快捷选文件面板，保留上方完整文件浏览 Tab。
- 修复部分 Android WebView 中图片已解码却高度为零、预览空白的问题，表格高度限制也改用实际视口计算。
- SVG 默认适配预览区全部宽度并保持比例，长图支持纵向滚动；双击放大，再双击恢复适宽，继续支持预览 / 源码切换和长按保存。
- 修复 Markdown 双星号加粗在中文引号、冒号、括号等边界原样显示的问题，代码块与转义星号仍保留字面含义。
- 收藏页移除「上拉继续加载」提示，保留滑到底部自动加载和正在加载的状态。
- 预览诊断收进「我的 → 更多 → 开发者选项」，默认关闭，按本机账号记住设置。
- GitHub App 的 Starring 已设置为 Read and write，仓库内容、Issues、Metadata 保持只读。已有用户如遇 Star 权限提示，请重新登录并接受权限更新。

## 验证与边界

101 项 Android 自动化测试、17 项阅读器测试、Release 构建与 Release Lint 均通过；已检查 APK 版本、不可调试标志、签名及与此前版本的证书兼容性，并在已连接的真机上完成覆盖安装。

图片预览空白问题已在 OnePlus 8T（Android 14、WebView 156）真机复现并由用户确认修复。SVG 适宽、缩放和视口变化另有浏览器及自动化回归验证；PDF、Excel 和登录 / Star 写入 / 私有仓库的完整端到端流程仍需更多设备验证。

私有仓库需用户本人和 GitHub App 均获准访问，组织仓库可能需要管理员批准。本机书签和访问记录暂不跨设备同步。当前版本尚未上架应用商店。

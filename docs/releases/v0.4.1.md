# Grove 0.4.1 · 快捷选文件面板（待发布草稿）

此版本尚未发布，正在积累修复。当前本地安装包仅用于验证，后续包及校验值以正式发布时为准。目前仅支持 Android 8.0 及以上；内部版本号 `11`，沿用 0.4.0 的开发签名。

## 本次修复

- 恢复阅读页底部「文件」的原型交互：弹出快捷选文件面板，不再跳转到上方「文件」Tab。
- 面板默认定位当前文件所在目录，支持进入文件夹、返回上级、返回根目录和筛选当前目录；标记正在阅读的文件。
- 选择新文件后收起面板并继续阅读；选择当前文件只关闭面板，不重新加载文档。
- 直接关闭面板保留文档、阅读进度和专注模式；加载失败在面板内重试，关闭后取消未完成请求。
- 上方「文件」Tab 继续提供完整文件浏览页，两种入口各有用途。

[查看选文件面板](https://github.com/yunxiange/grove/blob/v0.4.1/docs/screenshots/file-picker.png)

# Grove 0.4.0 · 预发布体验版

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.4.0-debug.apk** 安装，版本号 `0.4.0`，内部版本号 `10`。此版本与 0.3.2 使用相同的开发签名，可直接覆盖升级。

## 本次更新

- 仓库页按账号记住列表 / 卡片模式，切换页面或重新启动后继续使用上次选择。
- 项目操作菜单支持置顶与取消置顶；置顶项目优先显示，组内仍按当前排序，不随最近访问记录淘汰。
- 收藏右上角改为搜索入口，点击后再展开输入框；仍支持搜索全部 Star 和全部本机书签，下拉刷新继续可用。
- 发现页新增 GitHub 项目搜索，可结合领域、语言及新晋筛选，支持继续加载、下拉刷新与清除搜索。
- 修复收藏在 Star / 文档书签间切换时残留旧列表的问题，空书签页正确显示空状态。
- 个人页「更多功能」改为纸面风格底部面板，统一图标、分隔线和操作行。

## 验证与边界

75 项 Android 测试、APK 构建及 Lint 通过；修复前已通过页面测试复现视图模式丢失和空书签残留 Star，修复后回归通过。界面图使用 Compose / Robolectric 原生图形测试和示例数据生成。

此包使用开发签名，尚未完成真机验收。GitHub 登录、Star 写入和私有仓库访问仍需 GitHub App 的权限及安装授权，完整流程尚待设备验证。书签、置顶及阅读记录保存在本机，不跨设备同步。

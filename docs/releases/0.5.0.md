# Grove 0.5.0 · 表格自适应与紧凑书架

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.5.0.apk** 安装，版本号 `0.5.0`，内部版本号 `13`。

APK 使用不可调试的 Release 构建，沿用旧版本签名，可直接覆盖升级并保留账号、书签、足迹和偏好。本次发布到 GitHub，尚未上架应用商店。

## 本次更新

- 表格列宽由浏览器按实际字体与内容自然计算，短内容尽量完整显示；长内容达到宽度上限后换行，整张表超出阅读区时横向滚动。
- 修复作者、日期等较短内容被挤成多行的问题。排版不依赖列名、仓库名或文件路径，其他内容也采用同一套规则。
- 无表头的封面与标题链接集合自动排列，手机常规宽度下每行三本，后续条目自动换行；封面保持比例，长书名正常换行。
- 普通无表头数据表、带表头或跨行跨列的表格保留行列关系；Excel 独立预览沿用原布局。
- 保留 0.4.2 的 EPUB 阅读、PDF 缩放与手势、后台下载和缓存管理功能。

## 验证与边界

159 项 Android 自动化测试、27 项阅读器测试、Release 构建与 Release Lint 通过。浏览器使用实际书单与封面结构验证列宽、日期完整显示、长内容换行及三列封面效果；自动化回归验证链接、图片尺寸、条目顺序与表格行列关系。

已核对安装包版本、不可调试标志、签名和与旧版本的证书兼容性。本次未连接真机，Android WebView 的实际显示仍需设备验证。

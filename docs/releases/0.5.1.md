# Grove 0.5.1 · 阅读排版与快捷回顶

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.5.1.apk** 安装，版本号 `0.5.1`，内部版本号 `14`。

APK 使用不可调试的 Release 构建，沿用旧版本签名，可直接覆盖升级并保留账号、书签、足迹和偏好。本次发布到 GitHub，尚未上架应用商店。

## 本次更新

- 优化普通文档表格：较短表格优先在正文内完整显示，较长文字适度换行，减少不必要的横向滚动；确实放不下的宽表格仍可横向滚动。
- 表格按实际字体和内容测量，不依赖仓库、文件路径或列名。保留表格行列关系与封面书架的自动排列，独立 Excel 预览保持原布局。
- 普通文档正文与源码阅读新增「回到顶部」，向下阅读后在内容右下角出现；PDF、EPUB、图片和其他附件预览不显示此入口。
- 回顶按钮采用紧凑外框、小图标及淡暖灰按压反馈，同时保留易于点击的触控范围。

## 验证与边界

160 项 Android 自动化测试、32 项阅读器测试、Release 构建与 Release Lint 通过。已核对 APK 版本、不可调试标志、签名及与旧版的证书兼容性。

表格已在浏览器验证短表格适宽、长表格滚动和窗口变化后的重新排布；回顶已验证显示范围、点击回顶、阅读进度及附件预览排除。浏览器按压效果预览与原生自动化检查不能代替真机触摸体验验证，本次未连接真机。

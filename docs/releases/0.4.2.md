# Grove 0.4.2 · 电子书阅读与文件加载改进

目前仅支持 Android 8.0 及以上。下载附件 **Grove-0.4.2.apk** 安装，版本号 `0.4.2`，内部版本号 `12`。

这是 GitHub 正式版本，APK 为不可调试的 Release 构建。沿用已有版本的签名证书，可直接覆盖升级并保留账号、本机书签、足迹和偏好；尚未上架应用商店。

## 本次更新

- 新增未加密 EPUB 2 / 3 阅读：书内目录、顶部上一章 / 下一章、左右滑动切章、本章滚动进度、全书估算进度、字号与纸色。切章复用阅读页面，减少整页闪动；封面、序言等页面显示实际标题，不再编造章号。
- PDF 缩放改为每次 10%，比例与加减按钮放在全屏按钮左侧并收紧间距；点击比例恢复适宽。支持左右滑动翻页，放大时优先平移当前页；新页保留缩放比例。
- PDF / EPUB 流式下载，显示百分比与已下载大小，进度位于正文区域。支持切换导航、切到其他 App 与熄屏后继续下载；中断后保留片段，重试通过原始文件地址续传，已收齐的文件直接校验。文件版本变化或服务器无法续传时安全重新下载。
- Markdown、源码等普通文档加载时只显示细加载条，不再显示下载数字或续传提示。
- 修复书单等 Markdown 表格列宽过窄：按内容计算列宽，长段落适度换行，宽表格在正文区域内横向滚动。
- 仓库默认打开 README，移除顶部「阅读 / 文件 / Issues」切换；底部「文件」打开选文件面板，分支与 Issues 收进右上角更多。优化单行 owner / project 标题。
- 文件面板与完整文件列表的搜索默认收起，点击搜索图标展开，切换目录时复位。
- 新增「我的 → 更多 → 缓存管理」：查看缓存大小、一键清理；账号、书签、足迹、设置与阅读记录保留。

## 验证与边界

159 项 Android 自动化测试、23 项阅读器测试、Release 构建与 Release Lint 通过；浏览器验证书单表格列宽及横向滚动。发布前核对 APK 版本、不可调试标志、签名和与旧版本的证书兼容性。

本次未连接真机，新增后台 / 熄屏下载、电子书操作与手势尚需更多设备验证。系统强制结束进程后不保证自动续跑，重新打开文件可重试；续传要求文件版本未变且服务器支持范围请求。GitHub Contents API 自身的大文件限制仍适用。

EPUB 不支持 DRM、媒体播放或交互脚本，全书进度按章节与本章位置估算。PDF 不支持密码输入、批注和文本检索。私有仓库须用户与 GitHub App 均获准访问；本机书签和足迹暂不跨设备同步。
